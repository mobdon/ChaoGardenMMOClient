# Native PC character positions

The installed Steam executable (SHA-256 `4b1e09d782a2d919cbed2324ba2c0c78ef5fbe1677d400edab39608191f12c16`) contains character-specific tables for stage starts, stage ends, two-player introductions, and mission 2/3 endings. `stage_positions::for_stage(exe, stage)` resolves the PE sections and returns each authored row for that level, including its VA and distinct contexts. `read_rows` returns all 329 rows. The reader checks the executable hash, bounded table sizes, trailing level ID 91, and finite coordinates.

At City Escape (level 13), Sonic and Shadow each have single-player and two-player start poses. Both start at (0, 300, 340) in single-player, with yaw 0x4000. Two-player starts are (10, 300, 340) and (-10, 300, 340). Their ordinary end rows have separate single-player and two-player locations. The two characters have different two-player intro rows, and only Sonic has an explicit mission 2/3 completion row for this stage. The host selects an authored context; missing character or mission rows remain absent. This does not establish the retail scheduler's selection or fallback behavior.

The SA2 Mod Loader headers `SA2Variables.h` and `SA2Structs.h` provide VAs, array counts and layouts. SA Tools 786 independently maps the same tables in `GameConfig/PC_SA2/Characters.ini` (SHA-256 `0c46dde20ecb2733067894c50f2a0d7f04888d6284c727827b5ff1d8cd6096f1`). The installed `tools/lib/SplitTools.dll` (SHA-256 `5da8beb7288f1d7562fafd34c3b03a098d6ce177a8691ec98ae0df5b8254723f`) supplies independent SA2StartPosList.Load, SA2MiniPosList.LoadMulti and SA2MiniPosList.LoadEnd implementations. They read 29 tables, including seven City Escape rows. Their decoded level IDs, context counts, raw yaw words, coordinates and unknown fields have SHA-256 `7112dfb10e976a0a5b0ccacc737a4406192e8ede76b1cd738741284c3d969ea4`. The Rust integration test compares all 329 decoded records with this digest.

Run `tests/stage_positions_reference.ps1 -Tools <sa-tools-786> -Exe <sonic2app.exe> -Verbose` for the independent decoder and City rows. Set `SA2_SET_DIR` to the installed `resource/gd_PC` and run `cargo test --locked --test stage_positions_pc -- --ignored` for Rust. Neither step starts or modifies the game.

The on-disk bytes at the mapped PC entry points for RingLinear, RingCircle, BOARDCOL, ADXCHG and the character lookup routine could not be verified as usable retail instructions. The position comparison reads the actual PC data and checks independent field interpretations. It provides no direct executable-instruction parity claim for the gameplay callbacks.
