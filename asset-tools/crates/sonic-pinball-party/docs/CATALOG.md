# A3VE resource coverage

Evidence date: November 18, 2026. Source SHA-1 `92b5c19cb4dee8fdfc15a8abdc699822d5373042`; SHA-256 and exact source identity are pinned in `catalog.json`. Offsets below are hexadecimal **ROM file offsets**, except entries explicitly marked Garden. Garden is a decoded EWRAM image based at `0x02000000`, not a contiguous ROM slice.

The catalog combines exact structural candidates with curated spans. A strict stream decode proves its byte interpretation, not that a stream is used as art. Overlapping entries and shared pointer targets are retained; counts are not counts of unique playable assets. Scanning covers four-byte aligned type 0x10/0x30 headers from 0xC0, declared size 32..262144, at most 512 MiB aggregate attempted output. Unaligned streams, other encodings, uncompressed assets and unreachable content can be absent. The 73 structurally decodable RLE candidates are not claimed to be native RLE resources.

Every asset's full stored and decoded SHA-256, consumed length, address space and aligned same-space literal references are in `catalog.json`. Thumb function pointers use bit 0 and are documented in Garden notes instead of being misrepresented as direct data references. References do not establish runtime reachability.

Independent Python and Rust decoders compare every published span. Graphic parity includes six Garden tile/palette fingerprints and the board RGBA SHA-256 `947f0e412a386426ab6e363c3c3c225e9e18534c201bcd1a62d60bbd1515c09c`. Both complete native 256-word CRC tables match reflected polynomial `0x8408`. `tests/parity-evidence.json` is metadata-only reproducible evidence; native inputs and rendered images are excluded.

Advance 2 has different program size, identity and offsets. Some decoded resources match it exactly, but different resources shift by different amounts. This crate gates all locations against the complete A3VE identity; no global delta or Advance layout is accepted.
