# SA2 course enemy tasks

StageEnemies reads the original region-indexed, RLE-compressed enemy stream through the ROM table at 0xD4D94 and preserves every 7-byte record. Admission uses the native camera scan rectangles. The two executable species are Mon (type 0, original OBJ animation 478, priority 0x4010) and Buzzer (type 2, animation 482, priority 0x4030). Other records are inspectable but have no fabricated behavior.

Mon uses the original one-tile terrain anchoring probe, turns toward the player, enters its preparation animation inside strict player bounds, jumps using the native Q8 accumulator, and plays its landing animation. Buzzer patrols within its entity parameters, turns using its own animation, dives at the captured player position and returns to the same patrol offset with the original cooldown. Its offscreen test uses both the spawn point and displayed sprite. In normal single-player, easy difficulty excludes Buzzer only in the first zone. Call set_easy before the first admission when playing an easy save. Mon processes before Buzzer, and both run after the player task. A defeated marker remains consumed for the current stage load; camera culling restores the marker.

Shared damage uses the two player animation hitboxes in the original order. Player attack and item invincibility are distinct defeat paths. Normal contact queues the next hurt transition and applies the source shield, ring loss, timer, layer reset, or death flags. Ring-scatter, homing target, sound, relative recoil, score/animal/dust presentation and extra-life music cross an explicit event boundary to the host. The module does not render defeat effects, execute following player transitions, emulate hardware, or implement Cheese companion attacks, multiplayer or boss recoil. The host must use the native ring-scatter behavior rather than crediting arbitrary replacement rings.
