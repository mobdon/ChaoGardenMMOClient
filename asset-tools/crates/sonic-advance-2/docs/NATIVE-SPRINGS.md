# SA2 course springs

This module implements original interactables 3–12 (ordinary cardinal, large diagonal and small diagonal springs) for normal gravity in single-player courses. Entity admission comes from the shared region scanner. Each spring uses the verified A2NE ROM animation, variant and flip table at 0xD52E0, the adjacent transition and sound tables, and the active animation hitbox. Collision starts the original active animation and queues the sound ID; the host owns sound playback, task ordering, and player animation selection. New object graphics are not drawn by hand.

The launch initializer implements the normal-gravity cases in Player_TouchNormalSpring, including motion flags, facing, sprite offset compensation, the grounded horizontal boost, Music Plant scaling, water and trick delay. Its boundary is the entry to Player_8029074; the host must invoke that callback on the launch frame, invalidate the previous character state, and consume the forced sprite restart. Springs select the last transition written in original task order. Bouncy, floating and flying springs are separate objects. Boss-stage camera compensation, inverted gravity and complete game execution are outside this module.

Evidence: SAT-R/sa2 commit 2dd3f17d30cd3c156e508aac0017620ae485b9ba, src/game/sa2/stage/interactables/spring.c, src/game/shared/stage/player.c, src/game/shared/stage/collision_1.c and include/rect.h. The native_spring_oracle.py and native_contact_oracle.py tests compile locally supplied source only into an ignored .local directory. The 4,096 launch initializations compare 16 fields at callback entry (SHA-256 183af4ac1906b6c22cb39e2445ab7513fb70837a05b7c623964472b4a905fb9d). The 19,208 contact cases compare collision masks and resulting ground speed (124c771a5154f0fea8d9a625a05489aebc58e25a3ff613ee54205b9d48890b7e). ROM-backed source_native_springs tests exercise stage admission, the three graphics families, top-edge contact, transition, active/idle animation, despawn and readmission. These comparisons do not establish whole-frame game or audio parity.
