# Sonic combat callbacks

The host supplies previously selected targets after the player task and resets the target each player frame. Only Sonic considers these candidates. Source Player_UpdateHomingPosition subtracts in Q8 before converting to pixels, compares strict squared distance, and uses the integer octant-ratio function sub_8004418 with the 110-degree cutoff. Equal-distance ties preserve the first accepted object. The Sonic target is separate from Cream's Cheese target.

The attack and recoil initializers stop at entry to the next player callback. The host sets the 60-frame signed timer and requests sound 112 on homing launch, dispatches Player_Uncurl immediately on recoil, and sets hurt immunity to 120 on hurt entry. Homing decrements the timer before control/physics: reaching -1 clears the boost-effect flag and selects the falling pose. After physics it writes transition 1 if the player is no longer airborne. Later native tasks can overwrite that transition. Hurt uses bounds, gravity, position, then collision; it does not run air steering or relax rotation. The end-of-player-task timer decrement is inhibited only by char state 20; a stunned pose (21) does decrement it.
