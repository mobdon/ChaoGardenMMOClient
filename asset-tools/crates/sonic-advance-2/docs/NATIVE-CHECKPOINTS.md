# SA2 course checkpoints

The original checkpoint is two objects. Entity 43 draws animation 531, runs a course-specific background palette script, and requests sound 152 on activation. Entity 45 is an invisible route marker; it updates the same checkpoint and never plays that sound. Neither tests vertical player proximity or requires a prior frame to the left. Both first cull against the camera; an admitted callback accepts equality with the checkpoint X and ignores dead or interactable-overridden players.

Both store the original course destination from the verified ROM table at 0xD63FC and capture the lifecycle checkpoint clock. The visible object runs its hit animation through its final display, then stops drawing. When it re-enters view with a checkpoint already reached, only the background palette loader remains visible in the stage tiles; it does not draw a new ball. An out-of-camera task restores its entity marker; a silent marker which completes normally does not. Already-active visible or silent tasks can still update checkpoint time under the conditions of their own original callbacks even if a different route marker already triggered.

Source: SAT-R/sa2 2dd3f17d30cd3c156e508aac0017620ae485b9ba, src/game/sa2/stage/interactables/leaf_forest/checkpoint.c, src/game/shared/stage/palette_loader.c, src/background.c, src/task.c. The native loaders use BG not OBJ color RAM. Their scripts alternate two ROM palettes at two frames each and restore their first palette on task destruction. The supported manager accounts for previously active layer tasks and checkpoint palette tasks when deciding if a newly inserted same-priority palette starts on the current frame. Other still-unported tasks may change that first-frame timing. This object module does not implement emulation or persistent save writes.

The ROM-gated source_native_checkpoints test exercises visible activation in every represented regular course where that object occurs across all seven zones; checks original OBJ script 531 can render opaque pixels; validates all 16 palette colors across both phases, restoration, silent route crossing, camera removal before crossing, X equality, both suppression flags, post-use invisibility, and a return after despawning. The shared placement suite independently compares the original stage data with the source CSVs.
