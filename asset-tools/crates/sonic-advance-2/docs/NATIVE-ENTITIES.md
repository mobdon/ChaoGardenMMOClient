# Interactable placements and collision-layer switches

The A2NE interactable table starts at ROM offset `0x0D4C84`. Its 31 populated stage IDs refer to 24 distinct layouts. The region container is shared with rings. Interactables have seven bytes per record, giving two tile coordinates, a type, and four parameters. The reader preserves all four parameter bytes, including signed values in their original representation.

`tests/source_native_entities.rs` checks every placement against fingerprints derived independently from the 24 stage-authoring CSVs in SAT-R/sa2 commit `2dd3f17d30cd3c156e508aac0017620ae485b9ba`. The CSVs contain 5,183 records across the distinct layouts. Leaf Forest Act 1 has 232 records, including 97 collision-layer switches. The catalog records the Git blob ID of every CSV. The type-name map comes from `include/constants/sa2/interactables.h`, Git blob `0b8659882bf45688ff14c1686ddc1bd7e1e0537c`.

In `src/game/sa2/stage/interactables/leaf_forest/toggle_player_layer.c` (blob `66c946518dc45bdff44b48c80cb5fba0f19725ca`), types 0 and 1 select the foreground and background collision layers. They test the player's integer center against a rectangle with inclusive bounds. The entity's world position is the top-left corner. Its last two parameter bytes give width and height in tiles. A hit replaces the low layer bit and clears movement bit 0x01000000. Terrain probes use the resulting layer. Display priority and camera parallax are separate systems.

The host models the entity manager's initial/full scan, horizontal then vertical camera strips, and original activation order for the supported tasks. Trigger tasks perform their last collision check before despawning; returning the camera can create them again. The original entity manager and these tasks run at priority 0x2000, before the player at 0x3000. The scoped dispatcher models active layer tasks as the manager's equal-priority followers. Other object tasks can affect the first dispatch of a newly created trigger in the original scheduler; their behavior and whole-stage task-order parity remain unfinished.

The recorded Leaf Forest boundary at (3360, 744) is shared by two triggers. Their placement order selects the background there; moving one pixel to the right selects the foreground. The opt-in test checks that overlap, untouched upper layer bits, exiting the rectangle, removal outside the camera and later reactivation. Set `A2NE_ROM` and run `cargo test --test source_native_entities -- --ignored`. To regenerate the source fingerprints use `python tests/reference_ring_layouts.py REFERENCE_ROOT REPORT.json --interactables`.
