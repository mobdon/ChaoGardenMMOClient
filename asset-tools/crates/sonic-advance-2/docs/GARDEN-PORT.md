# A2NE Tiny Garden execution checkpoint

The user-supplied USA revision 0 ROM and its decompressed multiboot program both pass the existing full-file fingerprints before the runner starts. The Rust crate builds on its own, without a game service, network, external worktree or installed game. It only reads an owner-provided ROM when run. The Python standard-library desktop viewer sends inputs over the executable's stdin and displays the raw pixels Rust returns. CLI and GUI use the same state machine.

The static home scene uses original BG2 (4bpp) over BG3 (8bpp) with native screen and character bases, scroll, palette and transparency. Its independent oracle executes the actual init block at 0x020018C8 through 0x02001946 in Unicorn. Only BIOS memory copy/fill/decompression calls are supplied. Both complete 64 KiB BG VRAM buffers and both 240×160 RGBA backgrounds match independent fingerprints. The home painter adds original egg and fruit sprites, and a frozen Chao pose with a settled neutral emotion orb for supported appearances. Across 93 inspected cases, the actor pixels match 161 original hardware sprite entries emitted by the cartridge routines; it does not simulate roaming or mood animation. See [home sprite verification](NATIVE-GARDEN-HOME-ART.md), [the joined session tests](NATIVE-GARDEN-SESSION.md), and [minigame art](NATIVE-TINY-GARDEN-ART.md) for the OBJ and pixel limits.

The bounded game-side modules under `src/reused` for growth, fruit prices/effects, hatching, shop state and weeds were taken from this project's Rust `tiny-garden-core` at `db7a00bb9d70c2ae6708e42f0c14dabc1e76fa7b`. They implement the cartridge routines; no authority, account, online game or server adapter is included. Their zero-dependency local wiring, input-only integration tests, cartridge round/graphics evidence and independent process test live here. The MMO’s Janken, Ball and Search belong to other source tracks. No Android, deployment, server round trip or save migration is part of this port.

To reproduce, set `A2NE_ROM` to the local ROM. `CHAO_TINY_GARDEN_PAYLOAD` refers to the local verified decompressed Garden. Use the per-system oracle instructions to generate `A2NE_MEMORY_TRACE`, `A2NE_MEMORY_SESSION_INPUTS` and `A2NE_GARDEN_PROGRESS_ORACLE` privately. Run `cargo test --release --locked --all-targets -- --include-ignored` and `cargo clippy --locked --all-targets -- -D warnings` in the crate. To repeat the real process and desktop viewer checks, run:

```text
python tests/garden_cartridge_roundtrip.py PATH_TO_A2NE_GARDEN .local/proof
python tests/garden_viewer_smoke.py PATH_TO_A2NE_GARDEN PATH_TO_ROM
```

The Tk smoke test launches the real desktop viewer with its window withdrawn, hatches the starter egg, and opens Memory and Bounce in separate runs. It verifies that the displayed 480×320 pixels change from egg to Chao and from Chao to each minigame. It does not establish hardware or subjective playtest acceptance. Keep ROMs, save images, screenshots, trace rows, external reference code and decoded game assets out of Git.
