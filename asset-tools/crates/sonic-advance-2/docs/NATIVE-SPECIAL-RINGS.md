# Special rings in ordinary single-player stages

The verified USA ROM supplies seven type-103 interactables per ordinary act (98 over 14 acts), animation 730 idle/collect, and HUD animation 1128. No placements or art were rebuilt. StageEntities admits the object from the original stage table. The visible task offers its world position to Cream, checks the previous animation hitbox and then the supplied Cheese position, before checking camera bounds. Initially the hitbox is inactive. An uncollected off-camera object restores its map marker. On contact, count increments and cue 298 plays once; the object skips display that tick. On the next tick the collect animation starts. Its terminal frame is submitted before the following task destroys it. A collected map marker remains consumed until stage state is reset.

The HUD samples the count before the object task, updates the native 254-tick icon cycle even with zero rings, then displays one 8×8 icon per collected ring at (4+8i,31). Collision only mutates local gameplay, and no save or campaign reward is authored here. The retail unguarded Cheese null-pointer read depends upon GBA BIOS bus state. Only a real, supplied Cheese Q8 position participates in this branch; absence does not imply any synthetic position. Cream movement, a special-stage engine, audio mixing, whole-frame hardware blending and shared palette-bus emulation are outside this component.
